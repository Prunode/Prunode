# Security Policy

## Supported Versions

Currently, only the latest version of the project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.x| :white_check_mark: |
| < 1.0.x | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues. 

Instead, please report them by opening a GitHub Security Advisory directly in this repository:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories**.
3. Click on **Report a vulnerability**.

Alternatively, you can contact the maintainer directly if an email is provided in their GitHub profile.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is accepted, we will coordinate a release date with you and publish a security advisory.
